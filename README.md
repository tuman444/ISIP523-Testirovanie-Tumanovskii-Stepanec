# ПР 7

### 1. Описание процесса
Третья часть работы была посвящена анализу алгоритма обработки строк и символов. В ходе отладки проверялась работа метода, который некорректно обрабатывал входящие массивы данных (строки). Основная цель заключалась в изучении механизма «входа» в функции для проверки каждой строки кода внутри вызываемых методов.

### 2. Использованные инструменты отладки
* **Step Into (Шаг с заходом / F11):** Этот инструмент стал ключевым в данном задании. Он использовался для перехода из метода `Main` внутрь вспомогательного метода (например, `SendMessage`), чтобы проверить, как именно обрабатываются символы строки.
<img width="744" height="215" alt="image" src="https://github.com/user-attachments/assets/d362f4fd-a1e7-4d96-b412-c78f533d2e0b" />

* **Step Out (Шаг с выходом / Shift+F11):** Применялся для быстрого возврата в основной метод после того, как логика внутри функции была проверена, что значительно ускорило процесс отладки.
<img width="706" height="215" alt="image" src="https://github.com/user-attachments/assets/b5551d61-030f-4cf3-b5bf-8406a99f7137" />

* **Окно "Watch" (Контрольные значения):** Сюда были добавлены выражения для мониторинга индексов массива и текущего символа (`letters[i]`), чтобы отследить момент выхода за границы массива или некорректной замены символов.
<img width="1514" height="292" alt="image" src="https://github.com/user-attachments/assets/6576217f-856f-4a00-b8c2-51aaf354a7fc" />

* **Run to Click (Выполнение до щелчка):** Использовалось для быстрого перемещения выполнения программы к конкретной строке кода без установки постоянной точки останова.
