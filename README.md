---

### 1. Описание протестированных модулей
В ходе работы был разработан проект модульного тестирования `UnitTestProject1`, проверяющий логику работы приложения `PR4_Stepanec_Tumanovskii.Logic`. Тестирование охватывает три основных вычислительных класса:

* **`OneCaseCalculator`**: проверка парсинга вводимых значений (включая пустые строки, символы и буквы) и математических расчетов (включая работу с отрицательными числами, нулями и обработку исключения `DivideByZeroException`).
* **`TwoCaseCalculator`**: проверка логики ветвления для различных диапазонов, парсинга данных и корректности вычисления математических функций (`Sinh`, `Square`, `Exp`).
* **`ThreeCaseCalculator`**: проверка попадания значений в заданный диапазон (`IsInRange`), валидации ввода и обработки исключения `ArgumentOutOfRangeException` при выходе за границы допустимых значений.

Всего реализовано 26 модульных тестов с использованием методов объекта `Assert` (`IsTrue`, `IsFalse`, `AreEqual`) и атрибута `ExpectedException`.
