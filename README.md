### 3. Описание тестов

| Метод | Сценарий | Ожидаемый результат | Статус |
| :--- | :--- | :--- | :--- |
| `Debit_WithValidAmount` |	Списание допустимой суммы |	Баланс уменьшается на указанную сумму |	Успешно |
| `Debit_MoreThanBalance` |	Списание суммы > баланса | Исключение ArgumentOutOfRangeException с текстом "exceeds balance" | Успешно |
| `Credit_WithValidAmount`|	Пополнение на любую сумму > 0 | Баланс увеличивается на указанную сумму | Успешно |
| `Credit_LessThanZero` |	Пополнение на сумму < 0 | Исключение ArgumentOutOfRangeException с текстом "less than zero" |	Успешно |

---

### 4. Выводы
Тестирование методом "белого ящика" позволило выявить и устранить логическую ошибку в методе Debit (изначально сумма прибавлялась вместо вычитания).

Причина успешного выполнения:
  1. Тесты проходят успешно, так как бизнес-логика методов Debit и Credit теперь соответствует требованиям.
  2. Корректно обрабатываются математические операции.
  3. Реализована жесткая проверка входящих аргументов (валидация), которая выбрасывает информативные исключения при попытке передать неверные данные.
  4. Проведен рефакторинг тестов с использованием блоков try/catch, что позволяет проверять не только факт ошибки, но и точность сообщения об ошибке.
