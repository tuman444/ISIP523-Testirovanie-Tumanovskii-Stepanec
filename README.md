## 3. Описание предметной области
Матричный шифр перестановки — это метод симметричного шифрования, при котором символы открытого текста меняют свои 
позиции согласно определенной геометрической фигуре (матрице).
Алгоритм работы:
1. Выбираются размерности матрицы: количество строк ($rows$) и столбцов ($cols$).
2. Если длина текста меньше rows * cols, текст дополняется пробелами в конце.
3. Текст записывается в двумерный массив последовательно: строка за строкой.
4. Шифротекст формируется путем считывания символов из массива по вертикали: столбец за столбцом.
5. Дешифрование выполняется в обратном порядке: заполнение по столбцам и чтение по строкам.
