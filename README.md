# ПР7

## Задание 2: Отладка приложения «Галактики»

### 1. Описание процесса
В рамках этого задания выполнялась отладка приложения, работающего со списками объектов (модели Галактик). Основная задача заключалась в проверке корректности заполнения коллекции и вывода данных в консоль. Была выявлена ошибка в логике итерации/фильтрации данных.

### 2. Использованные инструменты отладки
* **Data Tips (Подсказки по данным):** Использовались для быстрого просмотра содержимого объектов в списке `theGalaxies` при наведении курсора на переменную в режиме паузы.

* **Conditional Breakpoints (Условные точки останова):** Была установлена точка останова с условием (например, `galaxy.Name == "Milky Way"`), чтобы остановить выполнение только на конкретном элементе списка. Это позволило не прокликивать цикл вручную.

* **Окно "Watch" (Контрольные значения):** Использовалось для наблюдения за конкретными свойствами объектов (например, `theGalaxies.Count`), которые менялись в процессе выполнения программы.
* **Step Into (Шаг с заходом / F11):** Применялся для проверки логики внутри конструктора класса `Galaxy`.
