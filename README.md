### Часть 1: Отладка приложения «Фибоначчи»

В ходе выполнения первой части работы была проведена отладка консольного приложения. Для локализации и устранения логической ошибки использовались следующие встроенные средства Microsoft Visual Studio:

1. Описание процесса
В ходе выполнения задания было проанализировано приложение для вычисления чисел Фибоначчи.
С помощью отладчика была выявлена ошибка в условии цикла for, из-за которой программа вычисляла значения некорректно.
